# promptmaxxing

A workspace for pushing prompts (and everything around them) to their limits.

## 🎮 Post Apocalyptic India — playable prototype

A top-down survival prototype built from the blueprint: *a man stuck in his house for 10 years
steps out into a zombie apocalypse, unaware if the zombies are gone.* Dark aesthetic; gore and
survival-instinct driven.

**Play:** open `index.html` in any browser (no build step, no dependencies).

- `GAME_DESIGN.md` — full design doc (systems, survivors, gore ecology)
- Highlights: rumor-instinct system that **lies to you when starving**, persistent blood/gore
  that lures zombies, The Patient One (a zombie pretending to be a corpse), survivors with real
  choices, memorial legacy on death, extraction win condition.
